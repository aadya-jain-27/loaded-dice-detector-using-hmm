The Loaded Dice Detector

Catching a dishonest casino using only the numbers it rolls.

The setup

The casino owns two dice that look the same

Fair die

Every face has a 1 in 6 chance.

Loaded die

Rolls a 6 half the time.

The problem

The dealer switches dice in secret. Can you spot it?

We only see the numbers. Tap the rolls you think came from the loaded die, then reveal.

The model

This is a Hidden Markov Model

A fancy name for: something hidden changes over time, and we only see clues.

Hidden

We can't see which die is used: Fair or Loaded.

Switching

The dealer doesn't switch often, so the same die stays for many rolls.

Numbers

Each die has its own chances. The loaded one loves 6.

The key idea

One 6 proves nothing. A streak of 6s does.
